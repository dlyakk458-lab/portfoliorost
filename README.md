# PORTFOLIO — Visual & Motion Designer

Премиум-портфолио, собранное под твои кейсы.

## Как открыть

1. Распакуй папку `portfolio`
2. Открой `index.html` в браузере (Chrome / Safari / Firefox)
3. Всё работает локально, без сервера

## Что внутри

- **Hero** — мощный первый экран, который сразу продаёт
- **01 Detailing** — 6 фото автомобилей (глянец, отражения)
- **02 Beauty** — до/после ретуши
- **03 Commercial** — исходник → Nike-креатив
- **04 Ads** — 3 стоматологических креатива
- **05 E-com** — 3 баннера NOVA
- **06 Video** — ссылки на Shorts / TikTok / IG Target + подкаст на 1 час
- **07 Thumbnails** — 3 YouTube-обложки
- **Contact** — блок призыва к действию

## Что обязательно поменять

В `index.html` найди секцию `#contact` и замени:

- `mailto:hello@example.com` → свою почту
- `https://t.me/` → свой Telegram

## Фичи

- Тёмный премиум-дизайн + золотой акцент
- Hover-эффекты и lightbox по клику на любое фото
- Плавные появления секций при скролле
- Адаптив под телефон
- Курсор-glow (на десктопе)

Готово. Открывай и кидай заказчице.
